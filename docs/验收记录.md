## 本次行为

即时灵感默认单文件保存，可配置年、季度、月、日和单文件。只配置一个保存目录，正文和附件均保存在其下；附件按照实际分卷文件名归组。默认 1024 KB 自动续卷，按 UTF-8 Markdown 字节数计算，独立附件不计入。一条灵感保持完整，超大单条允许独占一卷。

旧单文件作为历史来源保留，不自动搬移正文或附件。最近内容按记录时间跨文件汇总，保存目标和时间写入设备草稿，支持跨月与失败恢复判重。

## 实现复核后的修复

- 灵感提交标识绑定正文与附件版本。实际写入后返回报错，再编辑或添加附件会产生新的提交版本，不清除尚未提交的修改；跨月保存保留原附件及历史链接。
- 早期 v1 草稿缺少内容版本信息，保守恢复为未提交的 v2 草稿，避免静默丢失。可能包含已经保存的记录，恢复本身不会自动入库。
- 普通模式允许任务拖动并写回状态；布局编辑模式保留卡片排序。
- 布局同步按实际顺序移动兄弟卡片，保留焦点所在卡片、选区和输入法合成节点；待保存的同步删除卡片保留原位置。
- 冲突处理中同步改变配置来源时，备份旧冲突并刷新新位置预览，再次确认即可处理。备份期间连续出现的新来源也会重新读取并保留。
- 合并来源草稿先清理来源目录，全部成功后再删除主快照；部分清理失败时仍保留覆盖关系，重启不重复恢复已保存来源。
- 空仓库下首次点击保存才创建灵感笔记、必要的多级父目录及对应附件目录，打开创建界面不会创建空目录。
