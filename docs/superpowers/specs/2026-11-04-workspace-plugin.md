# 独立工作台插件设计

## 当前状态

此文档汇总经 grilling 逐轮确认的首版需求。插件已在本独立仓库实现，名称 Simple Space，插件 ID simple-space。当前为内测版，自动测试与实际平台验收分开记录。原有 vault 的 Home Pages 工作台保留不变。

本仓库从用户全新安装插件的流程开始实现和验收。不提供现有 Home Pages 工作台、历史配置或灵感草稿的迁移功能。

## 卡片与编辑

卡片类型固定为：欢迎卡片、即时灵感、快捷入口、待办任务、最近笔记、统计卡片。

首版每个 vault 提供一个工作台，同一种卡片可以添加多张。用户在工作台中添加卡片、选择类型、拖动位置、调整宽高，并通过卡片设置修改标题和内容来源。编辑完成后退出编辑模式，避免误拖。删除卡片只移除工作台中的展示，关联笔记、图片、录音和待办继续保留。

首次安装生成包含六种卡片的通用模板，沿用当前工作台的简洁视觉风格，用户可自行修改。模板不携带个人项目或笔记内容；灵感笔记、附件目录等在第一次实际保存时创建。插件更新保留用户自己的布局。

每张卡片独立配置内容来源；灵感统一配置保存目录，正文和附件随拆分规则保存在该目录下；日记目录单独配置。所有路径使用 vault 内相对路径。

### 卡片功能边界

- 欢迎卡片：保留问候、时钟、今日一句和紧凑台历入口。点击日期创建日记时，优先使用核心“日记”插件的目录、日期格式和模板；未配置时使用工作台默认设置，并允许修改。
- 即时灵感：默认保存到 `Simple Space/即时灵感/灵感.md`，默认单文件，可选年、季度、月、日和单文件。笔记与附件共用一个保存根目录，附件放在对应文件名的“附件”子目录中；默认达到 1024 KB 自动续卷，阈值可配置，单条内容保持完整。最近内容跨文件汇总，保留创建与返回，以及文字、链接、图片、文件、音频上传、直接录音和异常恢复能力。未保存草稿仅在当前设备自动备份，正式保存的笔记和附件才参与跨设备同步。草稿需使用不会随仓库或插件配置同步的本机存储，不把隐藏目录等同于本机存储。
- 快捷入口：通过卡片设置管理入口及目标路径。
- 待办任务：首版支持普通 Markdown 待办、进行中和完成三种状态，修改状态只回写原复选框行。默认单文件保存到 `Simple Space/待办任务/待办任务.md`，正文和附件共用保存目录，支持年、季度、月、日及大小续卷；旧来源继续可读。创建支持图片、文件、音频、直接录音、视频和系统录屏文件上传，不直接采集屏幕。附件与说明缩进保存在任务后，看板按需展开详情。未保存媒体使用设备 IndexedDB 备份，返回等待最终录音片段，备份失败保留编辑器。第三方 Tasks、Dataview 集成留后续版本。
- 最近笔记：展示近期笔记，来源范围通过卡片设置管理。
- 统计卡片：展示仓库统计，统计项目通过卡片设置管理。

### 平台与布局

插件代码和样式随插件包分发，不依赖 Home Pages 或外部 CSS 代码片段。Windows、macOS、iOS/iPadOS 和 Android 均为首版验收平台；本机代码检查不能代替其他平台真机验收。

不同设备同步同一套卡片及顺序；手机自动单列显示，桌面按配置的宽高排列。首版不分别维护手机和桌面两份布局。

## 配置存储

新安装默认在笔记目录 `Simple Space/workspace.json` 保存正式配置，首次启用时创建目录和配置；已有有效文件直接采用，无效文件不覆盖。`.obsidian/plugins/simple-space/data.json` 保留配置位置和启动缓存，也可手动切回插件目录模式。不要求用户手动创建配置文件。

插件设置提供“配置存储位置”：新安装默认选择“自定义目录”并填入 `Simple Space`，也可切换为“插件目录”。自定义模式支持选择仓库内目录或输入相对路径，包括仓库根目录。插件在所选目录下自动管理 `workspace.json`，无需用户选择或创建 Markdown 笔记。

### 指定配置目录

1. 目录限定在当前仓库内，不接受仓库外绝对路径或越界路径。目录选择器提供“仓库根目录”；内部用 `.` 表示根目录，不将其解释为操作系统根目录。
2. 选择仓库根目录时，目标为 `<vault>/workspace.json`；选择 `工作台配置` 时，目标为 `<vault>/工作台配置/workspace.json`。
3. 用户保存存储设置时，目录及必要父目录不存在则自动创建；配置文件不存在则以当前有效工作台配置创建。创建或写入失败时保留原存储方式和布局，并显示原因。
4. 目标文件已包含有效工作台配置时，加载该配置，不用当前布局覆盖它。目标为空文件时，可在这次明确的设置操作中使用当前配置初始化。
5. 目标内容损坏、版本不受支持，或目录路径实际指向一个文件时，提示错误并保留当前有效布局，不自动覆盖现有文件。

自定义配置文件使用带版本号的 JSON，保存卡片、布局和工作台设置，不包含插件代码与样式。用户日常只操作工作台界面，变更自动写入所选配置文件，无需编辑 JSON。不使用 Markdown 代码块或为文件自动添加 `.md` 扩展名。

存储模式和所选目录仍保存在插件 data.json 中，以便下次启动找到配置。其他设备可同步该设置，或首次选择相同目录。自定义模式下，目录未选定时不能提交，根目录必须明确选择，不能用空字符串同时表示根目录和默认存储。

### 配置发现

只同步 workspace.json 本身不会自动替设备选择配置来源。插件查找带有本插件格式标记的 workspace.json，发现后提示用户选择，不悄悄切换正在使用的配置；多个候选文件应显示路径供选择。不能仅凭文件名就把无关 JSON 认作工作台配置。

### 切回默认存储

选择“插件目录”并保存时，先把当前有效配置写入 data.json，再切换来源。保留原自定义目录及 workspace.json，不删除文件。写入失败时不切换。

### 自动保存与外部变更

每次仅有一个配置来源负责工作台配置的读写，避免 data.json 与自定义 workspace.json 相互覆盖。插件在适当时机保存布局，监听外部配置变更并自动应用；不以整页重建方式打断正在输入或录音的灵感卡片。

自动创建目录与配置文件发生在用户明确保存存储设置时。启动或同步过程中目标暂时不可读、消失或内容不完整时，保留上次有效布局并提示，不主动用默认配置重建或覆盖远端数据。文件恢复后重新读取。

## 同步边界

插件不自行提供云端同步，也不依赖 LiveSync。

- 默认 `Simple Space/workspace.json` 随普通文件同步；插件目录模式的 data.json 需要相应插件配置或隐藏文件同步机制。
- 自定义目录：workspace.json 随普通文件同步；目标设备首次选择该目录或同步来源设置后即可使用。官方 Sync 需开启其他文件类型同步，目录不能被用户的同步规则排除。若用户选择隐藏目录，仍受对应服务的隐藏文件同步规则约束。
- 插件代码和样式：各设备安装、更新插件。

电脑和手机分别离线修改后，若无法确认变更可安全合并，保留两份并提示选择版本，不按最后保存时间静默覆盖。首版优先保证可恢复，不承诺自动合并所有并发修改。

## 导入与导出

提供导入、导出工作台配置的按钮，默认存储模式下也不要求用户手动寻找 data.json。导出内容包含卡片、布局和来源路径，不包含笔记正文、图片、录音或其他附件。

导入时先验证并展示预览，用户确认后替换当前布局，原有笔记和附件不受影响。导出文件保留来源路径，接收方可能需要调整到自己仓库中的实际路径。

## 发布与验收

先在新的插件仓库发布测试版本，提供可安装的插件包和说明。完成 Windows、macOS、iOS/iPadOS、Android 验收后，再提交 Obsidian 社区插件目录，面向普通用户通过插件市场安装和更新。

首版验收覆盖全新安装、六种卡片的添加与编辑、同类型多卡、手机布局、灵感录音及草稿恢复、任务回写、两种配置存储和根目录选择、配置发现、同步后的自动应用、冲突保留、导入导出以及更新后保留自定义布局。涉及第三方代码时保留对应许可声明。
